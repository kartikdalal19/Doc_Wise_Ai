# DocuMind AI

## Overview

DocuMind AI is an intelligent Retrieval-Augmented Generation (RAG)
system that allows users to upload documents, ask questions,
generate summaries, and verify factual claims using trusted
external sources.

## Features

- PDF, DOCX and TXT support
- Semantic search
- Conversational Q&A
- Document summarization
- Fact verification
- Source citations
- Multi-document support

## Tech Stack

- Python
- FastAPI
- Streamlit
- LangChain
- FAISS
- Groq
